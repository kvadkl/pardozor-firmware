# ПарДозор 0.5.1

Дата выпуска: **17 ноября 2026**. Совместимое исправление версии 0.5.0.

Файл `pardozor-0.5.1.bin` — **1 718 912 байт**.

SHA-256: `a88d3418188e6e47e0a7b98a038bb1f0b5d630131e8b3179a1c0f509644dee5f`.

## Исправлено

- Исправлено скачивание прошивки по длинным адресам перенаправления GitHub. Увеличен буфер HTTP-запроса; адрес файла с подписью больше не обрезается из-за прежнего ограничения.
- Ошибки отправки HTTP-запроса больше не выдаются за неисправность даты или сертификата. Сообщение содержит сервер и точные коды HTTP/TLS; отдельно определяются ошибки DNS, проверки сертификата и тайм-аута.
- Добавлена явная проверка ошибок получения HTTP-заголовков. В диагностике отказа отображается доступная память; секретные параметры подписанной ссылки в журнал не попадают.

Проверка сертификатов HTTPS, SHA-256 и совместимости образа сохранена. Настройки, журналы, таблица разделов и логика температурного контроля/клапана не менялись.

## Как перейти с 0.5.0 или более ранней версии

**Первый переход на 0.5.1 выполните вручную файлом.** Ошибка находится в загрузчике старой прошивки: публикация нового файла сама по себе не исправляет уже установленный загрузчик. Старый прибор может увидеть новую версию, но снова сообщить об ошибке при скачивании.

1. Скачайте `pardozor-0.5.1.bin` из этой публикации на телефон или компьютер.
2. Остановите процесс, снимите контроль всех датчиков, выберите закрытый этап, верните управление этапу и дождитесь сохранения настроек.
3. Откройте **«Обновление прошивки» → «Загрузить файл вручную»**, выберите скачанный файл и загрузите его.
4. Не отключайте питание во время записи. После перезапуска проверьте версию **0.5.1**.

Последующие интернет-загрузки будут выполняться исправленным загрузчиком. Проверка обновлений в самой 0.5.1 покажет отсутствие новой версии, пока не опубликован следующий выпуск; это штатно и не является проверкой полного скачивания/установки.

## Совместимость

Только ПарДозор P1 на YD-ESP32-S3 N16R8 со штатной таблицей разделов. Файл — приложение для Web OTA, не полный дамп Flash. Не подходит для ESP32-WROOM-32 и ESP32-S3-Zero.

Прибор не управляет нагревом и не заменяет оператора. Обновляйте только вне рабочего процесса.
