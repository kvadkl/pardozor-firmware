# История пользовательских выпусков

## [0.5.1](https://github.com/kvadkl/pardozor-firmware/releases/tag/v0.5.1) — 17.11.2026

- Исправлена загрузка по длинным подписанным адресам GitHub.
- HTTP-ошибки больше не смешиваются с TLS, добавлены точные причины отказа и проверка HTTP-заголовков.
- Настройки, журналы и управление процессом не изменены.

С 0.5.0 и более ранних версий сначала установить 0.5.1 вручную файлом: старый загрузчик не исправляется одной публикацией нового образа.

[Описание и установка](releases/0.5.1.md)

## [0.5.0](https://github.com/kvadkl/pardozor-firmware/releases/tag/v0.5.0) — 17.11.2026

Первый выпуск публичного репозитория для ПарДозора P1 на ESP32-S3 N16R8.

- Четыре независимых датчика температуры, индивидуальные поправки по адресу датчика и настраиваемый температурный контроль.
- Этапы, шаблоны процессов, работа на себя, ручное управление и автоматика клапана отбора с восстановлением после отклонений.
- Этапная ШИМ клапана: процент отбора, цикл, минимумы открытия/закрытия и снижение после температурной остановки.
- Весы, расчётный объём, скорость отбора и цель; калькулятор.
- Графики, циклические журналы во Flash, дата и время событий, экспорт, отчёты и диагностика.
- До восьми сохранённых сетей Wi-Fi, поиск сетей и переподключение.
- Ручное обновление файлом и проверка новых пользовательских выпусков на GitHub с установкой из интернета по подтверждению.

[Полное описание и установка](releases/0.5.0.md)
