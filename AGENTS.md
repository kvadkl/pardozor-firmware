# Правила публичного репозитория прошивок ПарДозора

- Здесь находятся только пользовательские выпуски `X.Y.Z`, начиная с `0.5.0`.
- Никаких dev/alpha/beta/rc, Pre-release, внутренних бинарников, тестовых стендов, протоколов разработки и приватных исходников.
- Публиковать следующую версию, создавать её тег или менять `latest.json` только по отдельному явному запросу пользователя на выпуск именно этой версии. Разработка, сборка, передача файла для проверки и прохождение тестов такого разрешения не дают.
- Перед выпуском нужны успешные программные проверки и подтверждение испытаний на приборе. Не выдавать имитацию устройства за аппаратное испытание. Подтверждение оператора записывать во внутренней документации, не придумывать протокол измерений.
- SemVer: PATCH — совместимые исправления; MINOR — новые совместимые функции; MAJOR — несовместимые изменения. Не сбрасывать нумерацию из-за смены репозитория.
- Опубликованные образы не заменять под прежним номером. Следующее изменение — новая версия.
- В каждом выпуске: `.bin`, `SHA256SUMS.txt`, `manifest.json` и описание для пользователя. Тег `vX.Y.Z`, `isPrerelease=false`. Бинарники не коммитить в Git.
- `latest.json` — только stable `X.Y.Z`, только после публикации и проверки скачивания файлов. Не указывать на черновик, отсутствующий или отозванный выпуск.
- Не публиковать токены, Wi-Fi, NVS, журналы владельцев, полные Flash-дампы и локальные архивы.
- Публикация не разрешает установку на физический прибор. Она требует отдельного согласования.
- Не переписывать историю и не удалять выпуски без отдельного запроса. Перезапуск истории с 0.5.0 и удаление ранее ошибочно опубликованных тестовых выпусков разрешены пользователем только для первоначальной очистки 17.11.2026.
